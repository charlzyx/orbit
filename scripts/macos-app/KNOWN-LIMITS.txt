KNOWN LIMITS / 已知限制 — experimental Finder app

- This version includes Chinese Settings and dialog translations, preserving
  English, configuration identifiers and raw external error details.
- This version includes the GOPI wordmark and pixel PI icon, bounded process
  recovery without operation replay, independent commit model choice, and
  editor identity/rename fixes. These are tested code changes, not full parity.
- Launch-smoke PNGs are in-process content renders, not OS screen captures.
  Dedicated cloud Mac composer proof remains NOT_RUN (no runner assigned).

- Future macOS builds support Apple Silicon (arm64) only. Existing Intel
  releases and assets remain unchanged.
- The reported workspace-selection unresponsiveness is NOT confirmed fixed.
  This build includes asynchronous workspace/attachment dialogs and retains
  ordinary Pi configuration inheritance and bounded private diagnostic logs;
  these are not proof that the reported user-Mac hang is fixed.
- Pi now uses the launch user's normal ~/.pi/agent (or PI_CODING_AGENT_DIR).
  Orbit does not copy credentials. Stock Pi may perform its normal configuration
  migrations, settings writes and OAuth refresh. Orbit preferences and the
  versioned bundled runtime stay in private Application Support app data.
- App diagnostics contain allowlisted stages/results/timings, not conversation
  text, prompts, credentials, environment dumps or workspace paths. They are
  stored locally in the private app data folder and are not uploaded by the app.
- The file-open crash found in .2 is corrected: the main editor no longer
  mounts a duplicate Explorer tree. Whole-app regressions and fresh hosted
  Linux native first-file/two-tab captures passed. This is not a claim of
  complete editor acceptance on macOS. The right Explorer resize handle and
  source toolbar/geometry alignment are still incomplete.
- Full 139-feature source-derived acceptance is still open. No pixel-perfect
  claim: all 25 examined native comparison pairs differed; a matching screenshot
  is not a substitute for complete functional and native macOS acceptance.
- Review staged+edited-file duplication and hidden-window heartbeat have later
  code fixes with regression tests in this version. Their native parity is NOT
  accepted merely from those tests. Usage geometry has no fresh accepted pair.
- Pinned stock Ghostty scrollback/reflow fidelity and font/text-layout gaps
  remain. Experimental native-history code is not shipped.
- Hosted macOS first-frame/Ghostty/Pi RPC smoke is a release gate, not complete
  manual IME/clipboard/PTY/editor/provider/inference acceptance. No successful
  live model inference or user-Mac execution is claimed.
- No Developer ID signing or notarization; downloaded-app Gatekeeper acceptance
  remains unestablished. Stop if blocked; no security bypass is provided.
- Pi examples are omitted from redistributed runtime; docs/examples availability
  differs from a complete npm installation. See runtime manifest for exact list.
- Upstream historical Waku attribution and Pi bundled-code license provenance
  have documented caveats. Supplied notices are preserved; packaging is not a
  claim of exhaustive legal clearance. Read Resources/Licenses and provenance.
