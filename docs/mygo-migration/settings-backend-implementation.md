Baseline: original Orbit `299a32bc87fe3d4851bdb902d9c03dcf9bf99cac`; MyGo `9c69cf829ece196c5b3a3601f1c7bbe70526376f`; installed Pi metadata probe `1.4.0`. Work and tests were performed in cloud Linux, not on the user's Mac.

This is a checklist derived from the Rust handlers, not an inference from the Go screenshot. The current implementation is a **dirty working tree** identified by the SHA-256 manifest at the end. Neither published `80580ee` nor another checkpoint commit is evidence that these later changes were present. No row below asserts complete visual, OS, or full-surface parity.

## Verdict vocabulary

- **PASS, scoped behavior** means the named executed test demonstrated only the listed behavior.
- **Present, not independently accepted** means current Go code has the path, but this audit did not exercise its complete interaction sequence.
- **OPEN** means an identified interaction, persistence, or native integration acceptance remains.
- Every row's pixel verdict is **OPEN**. Native UI regression tests use MyGo's test renderer, not a launched native application or a Rust-vs-Go screenshot comparison.

## Explicit source/safety differences and remaining acceptance

1. Token arithmetic saturates at uint64 max rather than wrapping. Invalid counts are rejected instead of platform-dependent float-to-uint conversion.
2. CSV keeps a spreadsheet-formula injection guard, beyond the source quoting behavior. Unknown cost is empty, not0.
3. Skill deletion reports override-cleanup failure after the directory was actually deleted; Rust swallowed that cleanup failure. The caller must not present this as an untouched/retryable deletion.
4. Partial resource/metadata failures are returned with valid partial/fallback data rather than silently discarded. They are not permission to overwrite malformed stores.
5. Unix probe/Pi cancellation kills the process group; Windows hides the console but descendant termination has not been executed or established.
6. Source-generated insight narratives and complete localization are not replaced with fabricated text. The JSON export accepts only real caller-supplied insights; an empty insight list is not evidence of full source insight parity.
7. Provider/OAuth/quota auth state, native file dialogs, clipboard/reveal behavior, Pi installation, runtime reload/application and complete keyboard/focus are separate acceptance gates. Existing provider file tests do not prove those surfaces.
8. The independently rerun native resource/Providers tests establish only their named fixture sequences, including stale completions, failed writes, cancellation and actual temporary persistence. Host launch timing/overlay controls, complete keyboard focus, real runtime reload and external OS effects remain separate. Do not promote full rows based on the backend or renderer pass count.

The UI owner corrected all three in `internal/ui/run.go` (Offline option, root Overlay hook, `native.OpenPath`).
