## Narrow correction
Before draining UI updates, hidden-sidebar handoff captures the actual focused list/empty-sidebar handle, current owner token and page only if handoff is needed. After draining, it rechecks owner, page, hidden state and actual sidebar focus, then clears the cursor. It requests focus only if composer is currently visible (Chat, not full Review, not blocked setup). The titlebar's hide button alone uses public KeepFocus so pointer press cannot destroy the identity before handoff. No global button/input/toolkit behavior changed; opening sidebar and hiding it while another input or real terminal owns focus do not steal focus.

Palette collection distinguishes actual dismissal from command activation. Dismiss/toggle-close requests composer focus only under the same visible-composer predicate, without changing the page or text. It does not enqueue future focus for an unmounted/disabled composer or cancel unrelated focus requests. Command dispatch revokes the old modal restoration inside its actual callback, since OnTextKey runs after building the view; doing this only after the builder was too late. A newly opened modal retains its existing modal restoration intent. No generic modal policy changed and no caret/selection/IME Reset/SetText is added.
