## 优先处理的确定差异
1. **MCP apply 状态闭环/旧 session 刷新（P17）**：Go host 没有 `Applied()` 调用；不能把 `Restart()` 请求被接受当作真正应用完成。Rust `app/mcp_ui.rs:90–301` 有 fingerprint、延后重启及 applied 状态；Go 仅 `configApplyAfter` + `Agent.Restart()`。应先补事件确认/失败处理/parked invalidation 再宣称等价。
2. **侧栏缺少源动作（S10/S12/S13）**：session copy-path/reveal/details；workspace remove/copy path/mark icon/tint；sticky workspace header。现有后端 helper 不是 UI 完成。
3. **顶部 Quota/MCP（P09/P14）**：Go popover 没有 Rust Providers/MCP 双 tab 和隐藏供应商分组。`runtime_stats.go` 的注释提及 hidden preferences，不是实现证据。
4. **手动清理误受自动开关限制（U06）**：.4 的三层 guard 均依赖 enabled，Rust 手动入口不依赖；暂停修复尚未发包。正常用户验收不要做真实删除。
5. **已知构建限制**：自动 Orbit 更新无签名 feed/key；语言覆盖仍不全；独立首启/迁移页面被 Runtime 页面替代；.4 Explorer resize/Usage 几何改进尚在未发批次。

## 明日验收建议：先做真实正常工作，不拿已知缺项浪费时间
这些是建议的用户自验步骤，不是助手已执行结果；任何凭证、安装、删除、发布由用户自行决定。
1. 打开 .4，确认现有 Pi 模型/供应商可见；不要重新复制 key。创建一个无敏感文件的临时 workspace，然后切换最近文件夹与新建会话。工作区无响应是首要阻断，若仍存在可直接停止该流程。
2. 做一次短对话；切换到另一会话，再回来确认第一条进度/内容保留。关闭窗口（不是 Quit）再 Dock 重开，确认没多开 runtime、没丢会话。
3. 在 composer、Settings、file editor、terminal 各试一次 Cmd+P/Cmd+F、Escape 与 Tab。Settings 的 Escape 应先退出页面，不能误发 abort；终端中的键应去终端。
4. 现有会话做 rename/pin/archive/unarchive，再刷新和重开核对。不要使用 Delete 测试日常会话；copy-path/reveal/details 和 workspace 标记已知缺失无需寻找。
5. Settings 搜索 language/model/notification；切语言、theme/light-dark、字体/density 后退出再开，观察是否保留且界面仍可操作。已知部分菜单仍英文。
6. Usage Simple/Details 切换，选一个已知会话日期范围，search/multiselect/table sort/page/columns 与返回；导出到临时文件并取消一次 Save。记录错误/空值，不只看图表是否出现。
7. Skills/Plugins/MCP 先只读比较列表、scope、状态与已有 Pi 配置。MCP apply 完成/parked reload 已有缺口，若需要测试请用无真实 secrets 的本地 dummy server。
8. Runtime 查看 PID/stderr，已有任务结束后才 Stop/Start/Restart；核对真正恢复模型和会话而不是按钮变色。无需测试官方安装/迁移、OAuth 登出、自动升级或真实 Bug report 提交。
9. Privacy 可以查看 temp 清单；不要拿真实 session 做清理。自动 off→manual 按钮不可用是已知 .4 差异，不必重复报告为新问题。
10. 启用通知后做一条后台短任务（若用户愿意且系统已允许），验证一次 banner 点击打开正确会话。OS 通知/声音路径尚未验收。
