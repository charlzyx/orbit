## Confirmed, actionable .4 gaps

1. **C14 — Retry/compaction feedback is missing from chat.** Rust `crates/orbit-pi/src/app/events.rs:198` stores retry attempt/max/error and `app/view.rs:3882–3980` paints an above-composer retry banner with Cancel and a compaction status strip. Go `internal/agent/reducer.go:89–92` stores only a boolean; `internal/ui/app.go:700–715` goes directly from transcript to composer, and `chat.go:148–347` has no equivalent strip. `internal/ui/settings_agent.go:11–19` offers generic retry cancellation only on Settings. Therefore no accurate attempt count/provider-error banner can be displayed from the current Go projection. A provider stall may look like an unresponsive chat rather than a retry.
2. **C15 — Context control is reduced to text plus tooltip.** Rust `app/view.rs:3195–3251` mounts `context_meter::context_control`, hover summary, click details, refresh and compact callback; `crates/orbit-pi/src/context_meter.rs:120` defines usage slices. Go `internal/ui/chat.go:318–332` paints a percentage `ui.Text(...).Tooltip(detail)` only. Authoritative counters exist in `runtime_stats.go`, but there is no source-equivalent ring, detailed popover, conversation/other breakdown, or compact action at this control. Settings compact support is not the same interaction.
3. **C08 — Conversation navigation rail is absent.** Rust `transcript_view.rs:1369,1396` mounts rail markers and hover previews; `transcript.rs:877–905` persists rail-hint dismissal. Go `internal/ui/chat.go:15–110` mounts a virtual list and Jump to latest only. `actions.go:287–300` implements previous/next user-turn commands, but no rail renderer/hint state exists in the host. Do not mark C08 fully implemented on the strength of keyboard navigation alone.
4. **C09 — Remote Markdown images cannot load.** Go `internal/ui/app.go:262` installs `markdown.FileImages(o.Workspace)`; pinned MyGo `ui/markdown/image.go:22–38` rejects all `://` and `data:` URLs. Rust `transcript_view.rs:5699` normalizes image URLs and `:6304` renders `img(url)` with loading/fallback. This is a visible content omission for HTTPS screenshots in replies, not merely pixel spacing. This audit did not fetch any external image.
5. **C04 — Attach-file insertion ignores the caret.** Rust `app/composer_ops.rs:471–492` inserts a non-image file path at the composer caret, then focuses it. Go `internal/ui/attachments.go:52–58` appends `p + " "` to `Draft`. With text on both sides of the caret, the file lands at the end. The plus menu also exposes only Attach files / Paste image (`chat.go:209–218`) rather than the source's explicit attach-image/file/mention choices; basic `@` completion still exists.

## Correct stale missing-feature claims

The older acceptance supplement says structured ask, inline approval, replay and widget placement are not fully wired. That is not a valid current claim that these features are absent: `.4` has `internal/ui/extension_panels.go` (approval, buffered multi-question answers, back/next/custom text, submit), `internal/agent/extension_ui.go` (special request routing and replay), widget placements and focused tests. Native real-world acceptance is still open, but distinguish implemented from missing.

## Suggested short validation sequence for tomorrow

1. In a disposable project, send Chinese/emoji text with an IME; Shift+Enter newline; confirm Enter sends only after composition ends.
2. Pick an inherited model; run a harmless text request; while streaming add follow-up and steer, clear pending queue, stop, then send again. Check no lost draft or stuck busy state.
3. Attach a small image, paste/drop another, remove one, view preview; insert a file with the caret between existing words (known append-at-end mismatch).
4. Exercise a harmless tool output/error and two file-edit turns; fold/unfold, copy code, select across messages, open Review, search tool text and Escape.
5. Scroll away during streaming and return to latest. Rail previews are known absent in .4, not a user setup error.
6. Check context percentage and compact from available Settings controls. Detailed context popup is known absent; do not waste time trying to find it.
7. If a safe fixture exposes extension dialogs, approvals or questionnaire, test cancel/Back/final Submit and switch/reopen. Do not grant risky actual tools merely to test UI.
