# Orbit 工作台功能对照：供明日验收

审查时间：2026-10-25 14:00 UTC。Rust 基线 299a32bc87fe3d4851bdb902d9c03dcf9bf99cac；已发布 Go .4 为 0af37538a766d57243f9170f28c726327d053127。本轮是只读源码审查，没有运行新测试、使用用户 Mac、读取真实凭证或执行 GitHub 写操作。

## 先说结论

W01–W71 均有对应代码/接线的候选实现，但不能记为 71 项完成。下面发现的 UI 接线缺失足以证明尚未全功能 1:1。已有 .4 的 aggregate CI、Linux 原生/PTY测试和 macOS 安装启动烟测，不等于以下每行的真实 Mac 操作验收。

### 明确差异，按实用影响排序

1. **终端退出后恢复入口缺失（W65）**：Go `internal/terminal/panel.go:472` 有 Restart，生产源码没有调用方；`internal/ui/app.go:887–919` 只画标签、新建、关闭、隐藏和 grid，不显示 `TabInfo.Exited/Error/Tooltip`，没有横向可滚动 tab strip。Rust `terminal.rs:2035–2118` 有重启按钮、退出提示与重启操作。用户输入 exit 后可能只剩不能输入的 grid，不能把 domain Restart 测试当作 host 已接好。
2. **Review 长行与固定标题缺失（W36）**：Go `internal/ui/review.go:354–373` 以固定宽 RichText + MaxLines(1) 实现 no-wrap；`:587–628` 只有垂直 List，没有水平滚动器或 sticky file/section header。Rust `sidepane.rs:1416–1532` 有 h_scroll、固定标题及 push offset。长行尾部可能不可达，不只是视觉差一点。
3. **Review 上下文展开只有一种按钮（W35）**：Go `review.go:330–347` 只调用 ExpandGap(index,"both")；Rust `sidepane.rs:1750–1863` 支持从上/下边缘、双边或全部展开。底层支持不等于界面支持。
4. **Explorer 缺少部分源操作（W53–W56）**：.4 `files.go:174–296` 没有平台+左右键全展开/收起；context menu 没有默认应用打开、目录展开/收起项。`:297–355` 创建/重命名使用 modal Prompt；Rust `explorer/panel.rs:417–455,594,956–1003,1085,1365` 为 inline entry/rename、快捷键与完整菜单。
5. **窗口关闭后宿主维护不完整（W70/W02）**：Go `heartbeat.go:48–58` 只 Agent.Tick；`run.go:904–906` 明确说明未覆盖 MCP/background/layout。Rust `main_window.rs:143–160` 仍调用完整 OrbitApp.tick；`app/events.rs:18–60` 包含 MCP、布局落盘、通知/更新等工作。不要误报后台 Pi 完全停止，Pi draining 已实现；缺的是完整 host tick 等价性。
6. **Open-in 无搜索（W67）**：Go `app.go:780–793` 只是 Menu Item 循环；Rust `app/open_in.rs:213–217,300–308` 有搜索框与过滤。
7. **.4 已知 History/Explorer 差异（W03/W16/W18）**：History 短列表位置不正确、Explorer 没有调宽手柄；独立的 17 文件暂停批次在修这些。它们尚未在 .4，不应让用户下载 .4 后期待修复。布局每次 drag 直接 SaveLayout（`app.go:893–896`）也不等同 Rust `layout.rs` 的 settled debounce。

### 已检查的安全/边界，不夸大

- Git/Review/Worktree 路径包含真正 domain 操作，非纯按钮占位；GitHub handlers 通过 gh 参数化调用，PR merge/checkout、discard、worktree removal 有显式确认。并未进行真实远端 mutation。
- 编辑器保留保存失败时的 dirty tab 是明确安全差异，不是被误判的缺失；工作树 setup trust 写入失败时阻止继续也是既有安全差异。
- .4 修复重复 Explorer 导致的打开文件崩溃；当前工作区选择无响应仍未证实修复，由独立审查负责，不能混为同一缺陷。
- Terminal 保留 10,000 行预算，但底层 Ghostty 页式淘汰/重排与 Rust alacritty 完全等价未证明，实验 history 修改未发布。

## 明日优先验收顺序（只用临时测试仓库/文件）

1. 在两份普通临时仓库间切换，取消选择再确认选择；无响应即记录最后操作，暂不把后续项目判失败。
2. 新建并打开两个文本文件，编辑两个 tab，等待自动保存，关闭/重开确认；外部修改 clean 与 dirty 文件，验证 clean reload、dirty 保留与冲突提示。
3. 对同一文件制造 staged + unstaged 两部分，核对 Changes、Uncommitted、Staged、Unstaged；取消 Discard 不应修改文件；不要对真实仓库做 destructive 验收。
4. Review 切换 unified/split/wrap，长行、长 diff、上下文展开、上下文件/hunk跳转、全宽/收回。上述缺失项是已知差异，非用户操作错误。
5. 完成一次临时文件修改任务后查看 Last Turn；启动下一轮时前一轮仍可看；切回历史 turn 后不能被最新 turn 静默替换。真实模型/agent 回合尚需用户环境验收。
6. 打开终端运行无副作用命令，新建第二 tab，切换 workspace，验证旧 tab cwd 不变、新 tab 为新 cwd；测试 Escape/Ctrl+C、粘贴、中文输入；exit 后观察恢复入口（当前已知缺失）。
7. 创建临时 worktree，取消 setup consent 不运行脚本；完成后主/子 worktree 来回切换，关闭重开仍指向正确目录。删除/强制移除仅对可丢弃 fixture 验收，分支应保留。
8. 关闭主窗口但不 Quit，等待临时 agent 活动结束，再从 Dock 打开；区分 Pi 已完成与 host MCP/布局状态是否及时更新。
9. GitHub 首先检查无 gh/未登录提示与取消表单；真实评论、提交、合并不是必需的基础验收，不因未运行而假标通过。

## 下一项建议：先补终端退出/重启宿主接线（小范围，尚未实施）

相较 Review 横向滚动与 sticky 涉及测量/虚拟列表/焦点，W65 的域层已有能力，补宿主接线可更快闭合日常可用性缺口。

范围建议：只改 `internal/ui/app.go::terminal`（可抽独立 `terminal_host.go`）和对应 `terminal_host_test.go`，不改 pinned Ghostty、PTY domain、发布标记或现有 integration frozen tree。用 `Panel.Snapshot()` 驱动 active tab 的 Loading/Exited/Error，接现有 `Panel.Restart()`；保持其原始 cwd 和其他 tab。加横向 tabs/tooltip与每tab关闭时，必须验证避免事件冒泡选择已删除index。错误提示可已有全局toast，但源版的终端内持续错误/退出恢复卡片目前缺失，不能把toast当等价。

先写红测试：
- 真正临时PTY执行 `exit 7`，退出后 host 可找到退出说明与Restart按钮，而不是只调用domain Restart。
- 点击Restart，进程/Terminal身份改变且仍在原tab cwd；当前workspace已切换也不能悄悄改 cwd；第二tab对象和输出保持。
- 初始化命令失败时显示可理解的持续错误与重试，不显示永远转圈；错误解除后成功重启。
- 连续重启/关闭/切换tab，不能复活已关闭tab；加载中重复点不产生重复进程（需要复核是否现有domain已约束）。
- 多tab较窄窗口能横向访问末尾tab；关闭非active tab不误切换、active邻居正确；title与tooltip对应各自shell。
- Escape仍送往shell而不是abort agent；重新显示panel会聚焦shell。

测试使用临时目录和 `/bin/sh` 假内容，ORBIT_TERMINAL_TEST=1；UI Tester渲染真正host，不以API测试替代按钮点击。之后跑UI/terminal -race、完整aggregate与冻结原生capture；Linux结果只证明该scope，Mac真实IME/clipboard/系统焦点继续列待验收。新代码仍属于未发布改动，不能更新.4说明成已含修复。
