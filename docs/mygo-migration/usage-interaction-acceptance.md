# Usage native interaction acceptance

Pinned Rust baseline: `299a32bc87fe3d4851bdb902d9c03dcf9bf99cac`.
The following cases were written from the frozen source before implementation. Each case needs its own assertion. CPU captures prove only rendering, not OS execution or pixel parity.

## Concrete source-derived cases and expected outcomes

- U02.compare: `aggregate.rs::UsageSnapshot::compute`, `MetricDelta`, `derive_insights`. A finite range compares the immediately preceding equal-length range only if earlier store data exists. Preserve other scope filters, remove current bucket focus, and never synthesize a percentage from a zero denominator. All time has no comparison. Signals follow source thresholds/order and cap at four.
- U02.health: `aggregate.rs::{CacheStats,LatencyStats}`, `view.rs::{cache_body,latency_line}`. Cache traffic establishes availability; zero read with positive writes is a measured zero hit rate. No cache traffic is unavailable. Compute hit rate with input+read+write denominator, distinguish cached tokens from cache-read savings, and never invent savings currency. Latency average is available from actual samples; median/p95/p99 require twenty samples, using source nearest-rank percentile. Tool response time is separate.
- U03.model_identity: `model.rs::UsageFilter`, `filters.rs::dimension_rows`. Same model ID at different providers yields separate selectable entries. Selecting either or a union narrows requests/tools/errors and exported data to exactly those pairs, not a cross product.
- U03.multiselect: `filters.rs` and `page.rs::{toggle_filter_value,select_all,clear_selection}`. Search options, keep selected state after each toggle, select all visible results, clear the dimension, and preserve other dimensions. Menu keyboard navigation/Enter/Space/Escape works without submitting chat. Scope filters are transient, not persisted.
- U03.focus: `page.rs::{scope_to_day,set_focus,set_errors_only,set_cached_only,clear_filters}`. Heatmap selection changes custom date range and clears focus; a second click on the same day restores the preceding range. Chart/series/daily selection changes only bucket focus. Error-only and cached-only are mutually exclusive. Clear narrowing preserves date range. Active chips remove only their own scope.
- U03.calendar: `aggregate.rs::build_calendar`, `heatmap.rs`. Year bounds use scan timestamp, 365 fixed 24-hour days, local midnight and Monday padding. Padding is inert, out-of-year values do not set intensity maximum. Arrow-key inspection and selection expose the same day tooltip/value; stale scan time must not drift with wall clock.
- U04.tables: `page.rs::{query_sessions,query_series,query_buckets,query_failures}`, `table.rs`. Each table has independent search, sort, direction, selection, page, page size and hidden columns. Search runs before sorting/paging, without changing page summary/chart/filter. Equal sort keys have deterministic ties. Header cycles ascending, descending, source default. Changing search/sort/page size resets only the affected page; clamping never leaves an empty out-of-range page. Column widths are keyed per table and never below48px. Required identity columns cannot be hidden where source specifies them.
- U04.breakdown: `page.rs::BreakdownView`. Model/provider/workspace/tool tabs each retain search, hidden columns and page. Source breakdown sort is shared/persisted; table views are not. Show all rows via pagination, not a silent top-eight truncation. Tools show call/error/duration facts, not fabricated model token facts.
- U04.session: `view.rs::{session_context_menu,session_row_elements}`. Session selection is exact path keyed, titles/IDs remain available, top model is selected by traffic, full session lifetime is separate from summed response duration. Context menu opens actual session, copies ID, and scopes workspace/provider/model/session without silently retaining incompatible narrowing. Failure rows can open source session even when no billed usage exists.
- U04.persist: `page.rs::Prefs`. Only source-supported prefs persist: preset/custom bounds/metric/session sort+direction/page size/latency metric/session hidden columns/breakdown tab+sort/detail tab/mode. Searches, selected IDs, focus, column widths and other table state do not persist. Reject invalid enum strings and malformed custom bounds rather than showing a label that disagrees with the range. Preserve unrelated preferences.
- U02.lifecycle: `page.rs::{refresh,ensure_loaded}`. First load has skeleton; refresh keeps prior data with refresh status; failures keep truthful prior updated time and expose retry. Repeated requests coalesce; stale projection cannot replace a newer filter. Refresh/navigate does not duplicate source records.
- U04.export: `page.rs::export`, `view.rs::{export_csv,export_json}`. CSV exports scope-filtered requests, not session-table search/page; JSON records the session search and actual computed insight strings. Cancel has no write; failed write remains error, not success. OS save/cancel/overwrite still requires separate native execution.

- Comparison/health: `TestUsageComparisonCacheLatencyThresholdsAndFocusedPreviousWindow` asserts previous-window scope, no zero-denominator percentage, actual nearest-rank percentiles, write-only zero hit rate versus missing cache, all-time start and full focused chart axis.
- Provider/model identity and export: `TestUsageProviderScopedModelUnionFromRealStoreAndExports` scans real temporary JSONL with duplicate IDs at two providers, repeats exact pair unions, preserves prompt attribution, and checks CSV/JSON plus legacy field compatibility.
- Filters/focus: `TestUsageProviderScopedMultiselectSearchAllClearAndNativeEscape` and `TestUsageNativeFilterKeyboardAndRequestToggleExclusivity` exercise visible-result selection, independent dimension clearing, native search Enter, arrow/Space/Escape and error/cache exclusion.
- Calendar: `TestUsageCalendarScanAnchorDSTToggleAndKeyboard` covers stale scan anchor, DST fixed-duration bounds, day restoration and native keyboard. The quartile renderer is implemented; dedicated shape/level tests and matched pixels remain to be added.
- Tables: `TestUsageIndependentTablesQuerySearchSortPageAndColumns`, `TestUsageNativeTableSortCyclePagingResizeAndKeyboard`, `TestUsageSessionLifetimeTopModelToolsAndCoarseBuckets` assert independent state, query order, deterministic ties, paging, three-state sort, 48px resize clamp, source scope/open behavior, session lifetime versus response duration, top-model traffic and hourly-to-daily rollup.
- Persistence/context/export: `TestUsagePreferencesSourceSchemaAndTransientIsolation` and `TestUsageNativeContextMenuExportAndColumnPreferences` assert supported source enum preferences, inclusive custom-end schema, unknown-key retention, transient isolation, exact session ID/path context actions and table-search-independent CSV scope with JSON search/actual insights. - Lifecycle: `TestUsageRefreshCoalescesAndFailureKeepsLastSnapshot`, `TestUsageProjectionRejectsLateResultAndClonesFilterSlices`, `TestUsagePrunesRemovedScopeAndPageLifecycle` assert coalesced repeated refresh, retained prior data/time on failure, retry, stale projection rejection, cloned filter slices, pruning and stale/fresh entry. - Reasoning: `TestUsageReasoningPresenceMatchesFrozenCollector` checks missing/zero/positive/negative/fraction/null/string. Source `collect.rs` explicitly discards zero reasoning, unlike costs; positive reasoning remains an output subset, never added to total.

CPU images `probes/usageui/usage-{simple,details}-fixture-dark.png` were generated and visually inspected at 1470×922. Controls, heatmap, cards and tables render with explicit fixture data. These images do not validate a desktop event loop, OS dialogs, accessibility, or Rust pixel match.

Remaining work is explicit: source formatting and localized secondary labels, exact health-panel/response-time placement, additional KPI click targets, metric-specific unavailable presentation/coverage, dedicated line/area/quartile and lower-page CPU coverage, end-to-end history/OS export save/cancel/overwrite, all-platform native interaction and matched Rust/Go pixel gates. Full row parity stays unverified.

## Next source-shape cases (written before correction)

- U02.format: frozen `format.rs` compact values retain three significant digits and trim zeros; exact tooltip values group thousands. Small nonzero cost and rate never round to a claimed zero; shares below 100% never round to 100%. Response duration and session wall-clock span use their separate source formats.
- U02.board: available Requests/Tokens/Cache/Latency KPI cells select the matching chart metric and persist it. Unavailable cache/latency cells remain noninteractive and say unavailable. No-failure summary has no failure action. Measured response line belongs under the trend; tool duration belongs to tool breakdown.
- U02.health_shape: Token health is one raised section with composition/cache recessed panels side by side at source width threshold 820, stacked below it. Cache trend is full width only with two readable input/read buckets. Missing cache shows unavailable, not a false rate; measured write-only zero remains zero.
- U03.chart_geometry: nonempty positive-day quartiles ignore zero padding, busiest always level four. Focus keeps the full range axis. Chart Home/End/arrows/Enter/Escape inspect and toggle one real bucket; full readout uses exact values. Source scan synchronization notices the first session after an initially empty store.

- U04.responsive_plan (pre-change): source `view.rs::session_columns` reserves 48px chrome, 38px Open and a 180–460px flexible title. - U04.sort_ties (pre-change): source `page.rs::query_buckets/query_series/query_failures` resolves equal primary values by ascending timestamp, not lexicographic date labels or session title. Session ties use title then actual session ID.

- U02.latency_selector (pre-change): `view.rs:1584` renders Average/P50/P95/P99 as inline segments, never a dropdown. With 1–19 timed observations only Average is enabled; with 20 samples all registers are available.
